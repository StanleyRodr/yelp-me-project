# 011 — Tarea: Login

> Plan: `002-plan-frontend-estandarizacion-2026-11-19.md` · Rama: `feature/frontend-base` · Estado: Pendiente

## Objetivo
Inicio de sesión simulado del admin con sesión persistente y cierre de sesión.

## Pasos
1. `views/LoginView.vue`: composición con `components/auth/FormLogin.vue`.
2. `FormLogin`: correo, contraseña, mostrar/ocultar contraseña, error por campo; botón "Iniciar sesión" con círculo mientras valida.
3. `authService.login`: acepta solo admins de los mocks (`admin@yelpme.com`, `laura.admin@yelpme.com` / `Admin123*`). Usuario con rol `usuario` → error "Esta cuenta no tiene acceso al panel".
4. Store `auth`: guarda token y admin en `localStorage`; `cerrarSesion()` limpia y redirige a `/login`.
5. Navbar: menú con nombre del admin y "Cerrar sesión".

## Verificación
- Credenciales válidas → `/`. Inválidas → mensaje claro.
- Recargar mantiene sesión. Cerrar sesión → `/login` y rutas bloqueadas.

Pendiente.
